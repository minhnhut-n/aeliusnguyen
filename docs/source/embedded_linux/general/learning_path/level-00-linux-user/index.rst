Level 0 – Linux User (Beginner)
================================

Hướng dẫn này dành cho người mới bắt đầu làm quen với Linux. Bạn sẽ học cách sử dụng
shell, quản lý filesystem, các command line tools cơ bản và hiểu về process trong Linux.
