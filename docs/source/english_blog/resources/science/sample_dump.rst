Sample Dump - Science
===================

Template file for dumping new vocabulary, collocations and reading notes about science.

1. Vocabulary Dump
------------------

.. list-table::

   * - Word / Phrase
     - Meaning (EN/VI)

   * - hypothesis

* ``peer review`` — bình duyệt / đánh giá đồng cấp
* ``lab experiment`` — thí nghiệm trong phòng lab
